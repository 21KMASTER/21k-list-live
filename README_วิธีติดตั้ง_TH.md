# ชุดไฟล์ 21K List Live

ไฟล์ใน ZIP นี้: `index.html` (เว็บไซต์), `config.js` (URL Worker), `21k-live-worker.js` (ตัวเชื่อม JSONBin, Live และคลังเพลง), `icon-21k.svg` และ `manifest.webmanifest` (โลโก้และไอคอนสำหรับอุปกรณ์), และคู่มือนี้

## QR ใช้งานไม่ได้?

แก้ไว้แล้ว: หน้าเว็บส่งรหัสโชว์เป็น `?id=...` ให้ Worker เหมือนกันแล้ว ถ้า Worker ตั้งค่าถูกต้อง QR จะสร้างได้หลังจากกดปุ่มแชร์

## ตั้งค่าเว็บไซต์

1. ในชุดนี้ใส่ URL Worker `https://21k-list-sync.zieawlovepanda.workers.dev` ให้แล้ว (ไม่ต้องเติม `/show` ต่อท้าย)
2. อัปโหลด `index.html`, `config.js`, `icon-21k.svg` และ `manifest.webmanifest` ไปไว้ในโฟลเดอร์เดียวกันบน GitHub Pages
3. อย่าอัปโหลดกุญแจ JSONBin หรือรหัสลับลง GitHub

## ตั้งค่า Worker

ใช้ `21k-live-worker.js` ใน Cloudflare Worker ตัวเดิม แล้วกด Deploy จากนั้นตรวจว่าค่าใน Worker → Settings → Variables and Secrets ยังอยู่ครบ:
- `JSONBIN_BIN_ID`: Text, Bin ID ที่มีข้อมูล JSON แบบ object
- `JSONBIN_MASTER_KEY`: Secret, Master Key ใน JSONBin
- `OWNER_TOKEN`: Secret, รหัสที่เจ้าของจะกรอกในหน้าเว็บตอนเริ่ม Live

กด Deploy หลังเปลี่ยนโค้ดหรือตั้งค่า การรับคำขอเพลงจากเพื่อนจะเก็บไว้ในรายการของโชว์และแสดงที่หน้า Live เจ้าของ

ห้ามนำค่า Secret ไปใส่ในไฟล์เว็บไซต์หรือส่งให้ผู้อื่น

## ซิงก์คลังเพลงและค่าตั้งค่าระหว่าง MacBook กับ iPad

อัปเดตทั้งไฟล์หน้าเว็บบน GitHub Pages และ `21k-live-worker.js` ใน Worker ก่อน จากนั้นเปิดเว็บบนแต่ละเครื่องและกรอกรหัสควบคุมเดียวกันครั้งแรก ระบบจะรวมเพลงที่มีอยู่ทั้งสองเครื่องเข้าคลังส่วนกลาง แล้วซิงก์การเพิ่ม แก้ไข และลบเพลงอัตโนมัติ รวมถึง Groove และคำสั่งคุมคน การลบค่าตั้งค่าจะซิงก์ไปทุกเครื่องและไม่ถูกดึงกลับมาโดยเครื่องเก่า ปุ่ม **☁️ ซิงก์คลังเพลง** ใช้เริ่มซิงก์หรือสั่งซิงก์ใหม่ได้ สถานะจะแสดงข้างปุ่ม

หน้า **คลังเพลง** มีรายการ Playlist ปัจจุบันอยู่ด้านบน กดปุ่ม `+` บนเพลงเพื่อเพิ่มโดยไม่เปลี่ยนหน้า รายการเดียวกันจะอยู่ในหน้า **จัด Playlist** ด้วย และสามารถจัดลำดับ/นำเพลงออกจากแถบ Playlist ด้านบนได้

ค่าที่เคยเพิ่มไว้ก่อนอัปเดตยังเก็บอยู่ในเบราว์เซอร์เดิม เมื่อเปิดเว็บรุ่นใหม่นี้และกรอกรหัสควบคุมแล้ว ระบบจะนำค่าจากเครื่องนั้นไปรวมกับค่าบนคลาวด์

## หน้าจอ Live สำหรับเพื่อน

เมื่อเปิดหน้าจอ Live ทั้งเจ้าของและเพื่อนจะมีปุ่ม 4 ปุ่มให้เลือก: **รูปคอร์ด** (ดูภาพใหญ่แบบไร้กรอบ), **Setlist** (เห็นชื่อเพลง, Key และคอร์ดแรก), **ขอเพลง** และ **วันเกิด** (ฝากชื่อผู้ฉลอง พร้อมชื่อผู้ฝาก/ข้อความอวยพร) ในสองโหมดท้าย เพื่อนส่งรายการใหม่และเห็นรายการที่ทุกคนส่งไว้แล้วได้ รายการเดียวกันจะแสดงบนหน้าจอเจ้าของด้วย

หลังเพิ่มโหมดวันเกิด ต้องแทนที่โค้ด Worker ด้วยไฟล์ `21k-live-worker.js` รุ่นนี้แล้วกด Deploy ด้วย เพื่อให้ระบบบันทึกชื่อวันเกิดได้

## ถ้าเห็น Error 500

หลังอัปเดต Worker ให้ดูข้อความสถานะข้างปุ่มซิงก์อีกครั้ง รุ่นนี้แสดงข้อความที่ Worker ได้จาก JSONBin ให้ละเอียดขึ้น เช่น `HTTP 401` มักหมายถึง Master Key ไม่ถูกต้อง, `HTTP 404` อาจหมายถึง Bin ID ไม่ถูกต้อง, `HTTP 429` หมายถึงถูกจำกัดจำนวนคำขอชั่วคราว และ `Worker is not configured` หมายถึงยังขาดค่าตั้งค่าใน Variables and Secrets

ถ้ายังเห็น `HTTP 500` ให้เปิด Cloudflare → Worker ตัวนี้ → Logs แล้วจดเฉพาะข้อความข้อผิดพลาด (ห้ามส่ง Secret หรือ Master Key) เพราะต้องดูบันทึกของ Worker เพื่อระบุเหตุที่เกิดบนบัญชีจริง

ถ้ารหัสควบคุมที่ใช้กับ Worker เดิมถูกต้อง ไม่ต้องสร้าง Secret ใหม่ เพียงอัปเดตโค้ด Worker แล้ว Deploy

## ทดลอง

เพิ่มเพลงเข้า Playlist → เปิดหน้า Live → กด QR → กรอกรหัสควบคุมในช่องบนหน้าเว็บ → QR ควรปรากฏ จากนั้นสแกน QR จากโทรศัพท์อีกเครื่องแล้วลองส่งคำขอเพลง

URL Worker ตั้งค่าไว้แล้ว แต่ Bin ID, Master Key และรหัสควบคุมจริงต้องมาจากบัญชี Cloudflare/JSONBin ของคุณ
