# วิธีอัปเดตหน้าเว็บ 21K List

ชุดนี้เพิ่มระบบรับคำขอเพลงในหน้า Live, รูปแบบคลังเพลง 4 แบบ, ความคิดเห็น Playlist โปรด, การจัดลำดับเพลง และการเพิ่มเพลงระหว่างโชว์

## อัปเดตหน้าเว็บไซต์

1. แตกไฟล์ ZIP นี้
2. เข้า GitHub แล้วเปิด Repository เว็บไซต์ 21K List
3. เปิด `index.html` แล้วเลือกดินสอ **Edit this file**
4. แทนเนื้อหาเดิมทั้งหมดด้วยไฟล์ `index.html` จากชุดนี้
5. กด **Commit changes** แล้วรอ GitHub Pages อัปเดต
6. เปิดเว็บและรีเฟรชหน้า

ให้เก็บ `config.js` เดิมไว้ อย่าใส่ JSONBin Master Key ลงในไฟล์เว็บไซต์

## รับคำขอเพลงจากเพื่อนในหน้า Live

เพื่อนที่เปิด QR จะเห็นช่องกรอกชื่อเพลง ชื่อเล่น และหมายเหตุ เมื่อส่งแล้ว คำขอจะถูกเก็บกับข้อมูลโชว์ใน JSONBin หน้า Live ของเจ้าของจะแสดงรายการให้อัตโนมัติทุก 5 วินาที ทีมใช้รายการนี้เป็นไอเดียเพลงสำหรับแกะและซ้อม

### อัปเดต Cloudflare Worker (จำเป็นสำหรับการรับคำขอ)

1. สำรองโค้ด Worker ปัจจุบันไว้ก่อน
2. เปิดไฟล์ `21k-live-worker.js` จาก ZIP แล้วคัดลอกทั้งหมด
3. เข้า Cloudflare Dashboard → **Workers & Pages** → เลือก Worker ที่ URL อยู่ใน `config.js` → **Edit code**
4. แทนโค้ดเดิมด้วยโค้ดจากไฟล์ แล้วกด **Deploy**
5. ที่ Worker เปิด **Settings → Variables and Secrets** และตรวจ/ตั้งค่าต่อไปนี้:
   - `JSONBIN_BIN_ID`: Bin ID ที่เก็บข้อมูลโชว์
   - `JSONBIN_MASTER_KEY`: JSONBin Master Key ตั้งเป็น **Secret**
   - `OWNER_TOKEN`: รหัสควบคุมที่เจ้าของใช้ ตั้งเป็น **Secret** และให้ตรงกับรหัสที่กรอกในหน้าเว็บ
6. คง URL ใน `config.js` ไว้เหมือนเดิม แล้วเริ่มแชร์ด้วย QR ใหม่

Master Key อยู่ใน Cloudflare Worker เท่านั้น โค้ด Worker เก็บโชว์ในฟิลด์ `shows` ของ JSONBin และคงฟิลด์ข้อมูลเดิมอื่น ๆ ไว้ หากไม่ทราบ Bin ID หรือรหัสควบคุม ให้ดูจากการตั้งค่าเดิม ห้ามเดาหรือใส่ Master Key ในเว็บไซต์

## ใช้งานส่วนอื่น

- **คลังเพลง:** เลือก ปกติ / กลาง / เล็ก / แสดงชื่อเพลงอย่างเดียว เมนูจะจำค่าบนเบราว์เซอร์เครื่องนั้น
- **Playlist โปรด:** เขียนความคิดเห็นก่อนกดบันทึก แล้วเปิดอ่านได้ในการ์ด Playlist โปรด
- **เรียงเพลง:** ลากแถวเพลงบนคอมพิวเตอร์ หรือแตะลูกศร ⬆️/⬇️ บนโทรศัพท์
- **เพิ่มเพลงระหว่างโชว์:** หน้า Live ของเจ้าของกด **เพิ่มเพลงระหว่างโชว์** แล้วเลือกเพลงจากคลัง
